# Japanese set completeness audit — 2026-10-28

The active staging catalogue was compared read-only against all **462 Japanese
checklist groups** in [TCG Collector](https://www.tcgcollector.com/sets/jp).
The catalogue has **16,319 Japanese rows** across 206 ID-prefix groups; the live
primary counts exactly match the paired catalogue export used for this audit.
Active import: `PS-CATALOGUE-EN-JA-NEO2057-20261028`.

- **281 groups have no identified catalogue rows** after resolving known code/name aliases and source-specific recovery IDs.
- **55 groups are present but have fewer rows than the reference checklist.** These need card-level verification; the count difference alone is not a final missing-card count.
- **126 groups have equal or greater row counts.** This does not prove exact card/printing completeness.
- The 281 include **8 Mega-era** and **20 Scarlet & Violet-era** groups. Eleven are unnumbered-energy groups and thirteen are the source’s miscellaneous/Other groups; 257 are in the other era/product categories.

A “group” includes expansions, starter decks, promo pools and special products.
Some deck bundles overlap individual-deck groups; these numbers are not unique
printed set codes, unique missing cards or a claim of exhaustive worldwide coverage.
There are no announced-but-unreleased groups in this reference snapshot; its latest
listed release date is 2026-09-16. All 206 local prefixes were accounted for.

Code aliases were resolved (for example SM1+ → SM1p, MMB-P → MMBP,
MP in the Mega era → M-P). Legacy sets without printed codes were matched by
set identity. Existing pc-/pooka-/ra- recovery rows were included. Reused codes
were separated: Sword & Shield SC starter decks are not BW Shiny Collection,
and Miscellaneous Promos MP is not the Mega promo group.

[Pokémon’s official entry](https://www.pokemon-card.com/card-search/details.php/card/48264/regu/all)
confirms the owner’s MBG 003/021. The official product-search response was also
retained. TCGdex’s 186-set list is an additional cross-check, not the complete
baseline: it omits MBG and uses several alternate codes.

No catalogue, recognition settings, reference assets or phone index changed.
The previous 16,319/16,319 image figure measured existing rows only.
